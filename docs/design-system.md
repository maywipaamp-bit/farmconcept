## Typography
- Font Family: Noto Sans Thai
- Page Title: 28–32px
- Section Title: 20–24px
- Card Title: 18–20px
- Body: 16px
- Small: 14px
- Caption: 12px

## Spacing
ใช้ระยะมาตรฐานเท่านั้น
- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 48px

## Radius
- Small: 8px
- Input/Button: 12px
- Card: 16px
- Modal: 20px

## Shadow
ใช้ Soft Shadow เท่านั้น และไม่ควรใช้ทุก Component

## Responsive
- Mobile: ต่ำกว่า 768px
- Tablet: 768–1023px
- Desktop: 1024px ขึ้นไป

## UX Rules
- CTA หลักของแต่ละหน้าต้องชัดเจน
- ไม่ใช้สีมากเกินจำเป็น
- สีสถานะต้องสื่อความหมายตรงกันทั้งระบบ
- ตารางบนมือถือควรเปลี่ยนเป็น Card หรือ Horizontal Scroll
- Form Desktop ใช้ 2 คอลัมน์ได้ และ Mobile เป็น 1 คอลัมน์
