# Typography Standard — TheFarmConcept
**เอกสารนี้เป็นมาตรฐานฉบับใช้งาน แทนสเปกฟอนต์เดิมทั้งหมด**

แนวทาง: สเกลแคบแบบระบบงานข้อมูล (data-dense) — ตัวอักษรส่วนใหญ่อยู่ที่ 13–14px
ใช้ **สีและน้ำหนัก** แยกความสำคัญเป็นหลัก ใช้ **ขนาด** เฉพาะเมื่อจำเป็น
ตัวเลขใหญ่สงวนไว้สำหรับ KPI บนแดชบอร์ดเท่านั้น

ฟอนต์: **IBM Plex Sans Thai** (400 / 500 / 600) ข้อความไทยทั้งหมด
**IBM Plex Sans** (500 / 600) เฉพาะตัวเลข (KPI, จำนวน, %, จำนวนเงิน)
โหลด: `https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Thai:wght@400;500;600&family=IBM+Plex+Sans:wght@500;600&display=swap` (production ให้ self-host)

## สเกลมาตรฐาน — 7 ระดับ ใช้ได้ทุกหน้า

| ระดับ | ขนาด / น้ำหนัก | line-height | สี | ใช้กับ |
|---|---|---|---|---|
| **T1** Page title | 22px / 600 | 1.3 | `#1f2c20` | ชื่อหน้า (letter-spacing `-.015em`) |
| **T2** Section title | 16px / 600 | 1.35 | `#1f2c20` | หัวการ์ด · หัวแผงเมนู |
| **T3** Body / เนื้อตาราง | 13.5px / 400 | 1.55 | `#1f2c20` เนื้อหลัก · `#4a564a` เนื้อรอง | เนื้อในตาราง · รายการเมนู · ย่อหน้า |
| **T4** Label / หัวตาราง | 13px / 600 | 1.4 | `#55624f` (บนแถบเข้ม = `#ffffff`) | label ฟอร์ม · หัวคอลัมน์ |
| **T5** Meta / รายละเอียดรอง | 12px / 400 | 1.45 | `#7d8a7c` | บรรทัดรองใต้ชื่อ · คำอธิบายหัวการ์ด · หน่วย |
| **T6** Micro | 11px / 400 | 1.4 | `#9aa599` | footer · tick แกนกราฟ · ป้ายในกราฟ |
| **T7** Numeric KPI | 30px / 600 | 1 | `#1f2c20` | ตัวเลข KPI บนแดชบอร์ดเท่านั้น (Plex Sans, letter-spacing `-.02em`) |

**ขั้นต่ำ:** 11px — ต่ำกว่านี้ห้ามใช้ (เดิมมี 10.5px ให้เลิกใช้)
**ห้ามสร้างระดับใหม่** ถ้าจำเป็นต้องเน้น ให้เปลี่ยนน้ำหนัก (400 → 600) หรือสี ไม่ใช่เพิ่มขนาด

## ระดับเสริมที่อนุญาต (ใช้เท่าที่ระบุ)

| ชื่อ | ขนาด / น้ำหนัก | ใช้กับ |

| **N-lg** | 20px / 600 | ตัวเลขเด่นรอง — ยอดกลางโดนัท · ค่าเฉลี่ยในการ์ด |
| **N-md** | 15px / 600 | ตัวเลขเด่นในแผงย่อย · ตัวเลขในผลวิเคราะห์ |

## แยกตามหน้าจอ

### หน้ารายการ / ตารางข้อมูล (มาตรฐานหลักของระบบ)
- ชื่อหน้า **T1** · breadcrumb ใต้ชื่อ **T5**
- ปุ่มบนหัวหน้า **Btn** · ชิปตัวกรอง **Badge**
- การ์ดสรุปเหนือตาราง: ป้าย **T5** · ตัวเลข **N-lg** · หน่วยและบรรทัดล่าง **T6**
- หัวตาราง **T4** · เนื้อตาราง **T3** · บรรทัดรองใต้ชื่อ (รหัส, ชุมชน, สถานะ LINE) **T5** · ตัวเลข **N-sm** · ป้ายสถานะ **Badge**
- แถวตารางสูง ~48px · ทุกคอลัมน์ข้อความใช้ `minmax(0, 1fr)`

### หน้าเข้าสู่ระบบ
- ชื่อระบบใต้โลโก้ **T3** สี `#7d8a7c` จัดกึ่งกลาง
- label **T4** · input **Input** · ปุ่มแสดง/ซ่อนรหัสผ่าน **T5**
- ปุ่มเข้าสู่ระบบ / กิจกรรมทั้งหมด **Btn** · ลิงก์ลืมรหัสผ่าน **T5**
- ท้ายหน้า (เวอร์ชัน, ลิขสิทธิ์) **T6**

### ฟอร์มกรอกข้อมูล
- หัวฟอร์ม **T2** · label **T4** · input / dropdown / textarea **Input**
- คำอธิบายใต้ label **T5** · ข้อความ error **T5** สี `#c0504f`
- ปุ่มบันทึก / ยกเลิก **Btn**

### แบบประเมิน (มือถือ)
- หัว header **T2** (ขาว) · บรรทัดรอง **T5** (`rgba(255,255,255,.85)`)
- คำถาม **T3** น้ำหนัก 500 · หมายเหตุใต้คำถาม **T5**
- เลขในปุ่มสเกล 1–5 **N-lg** · คำกำกับใต้เลข **T6**
- ชิปตัวเลือก **Badge** · textarea **Input** · ปุ่มส่ง **Btn**
- **พื้นที่กดบนมือถือสูงไม่น้อยกว่า 44px**

### แดชบอร์ด
- overline **Overline** · ชื่อหน้า **T1**
- KPI: ป้าย **T5** · ตัวเลข **T7** · หน่วยและบรรทัดเปรียบเทียบ **T6**
- หัวการ์ด **T2** · คำอธิบายท้ายหัวการ์ด **T5** · หัวแผงย่อยในการ์ด **T5**
- ป้ายแถวกราฟ / ชื่อกลุ่ม **T5** · ตัวเลขท้ายแท่ง **N-sm** · % **T5**
- ยอดกลางโดนัท **N-lg** + หน่วย **T6**
- กราฟแนวโน้ม: tick แกน Y **T6** · ชื่อหัวข้อแกน X **T6** (`white-space: pre-line` + `word-break: keep-all`) · ป้ายค่าบนจุด **T6** น้ำหนัก 600 · ส่วนต่าง **T6** น้ำหนัก 600
- ผลวิเคราะห์: หัวแผง **T4** · ตัวเลข **N-md** · หัวข้อ **T5** น้ำหนัก 500 · คำอธิบาย **T5**
- Treemap: กล่องใหญ่ ชื่อ **T5** + ตัวเลข **N-md** · กล่องกลาง **T6** · กล่องเล็กมากซ่อนชื่อ เหลือตัวเลข **T6**
- Tooltip: หัวข้อ **T5** (ขาว) · key **T6** (`rgba(255,255,255,.62)`) · value **N-sm** (ขาว)

### เมนูด้านข้าง — **คงของเดิมในโปรเจกต์ ไม่ต้องแก้**
อ้างอิงเท่านั้น: ชื่อหมวด **T2** · รายการเมนู **T3** (รายการที่เลือกน้ำหนัก 600) · ท้ายแผง **T6**

## กฎการตัดบรรทัดข้อความไทย (บังคับ)
- **ห้าม** `white-space: nowrap` กับข้อความที่อาจยาวเกินคอลัมน์ — ให้ตัดบรรทัด หรือ `text-overflow: ellipsis` คู่กับ `min-width: 0`
- คอลัมน์กริดที่มีข้อความใช้ `minmax(0, 1fr)` ไม่ใช่ `1fr`
- ย่อหน้าเนื้อความใส่ `text-wrap: pretty`
- หัวข้อในกราฟที่ต้องขึ้นบรรทัดใหม่: `white-space: pre-line` + `word-break: keep-all` (ไทยไม่ตัดกลางคำ)
- หัวการ์ดกับคำอธิบายให้อยู่ใน flex ที่ `flex-wrap: wrap` เพื่อให้คำอธิบายตกบรรทัดที่สองได้
