## Reuse Rule
ก่อนสร้าง Component ใหม่ ให้ตรวจสอบว่า
1. Component เดิมปรับ Props ได้หรือไม่
2. สามารถเพิ่ม Variant ได้หรือไม่
3. สามารถแยกเป็น Base Component ได้หรือไม่

หากต้องสร้างใหม่ ต้องออกแบบให้รองรับหลายหน้าจอ ไม่ผูกกับหน้าจอเดียว
