# Screen Templates

## 1. CRUD List
เหมาะกับ ผู้ใช้งาน, พื้นที่, วิทยากร, หลักสูตร, รูปแบบกิจกรรม

โครงสร้าง
- Page Header
- Search
- Filter
- Add Button
- Table/Card List
- Row Action
- Pagination
- Empty State

## 2. Create/Edit Form
โครงสร้าง
- Page Header
- Breadcrumb
- Form Section
- Validation
- Sticky Action Bar หรือ Action Footer
- Save / Cancel

## 3. Detail
โครงสร้าง
- Header + Status
- Summary Information
- Tabs
- Related Data
- History/Timeline
- Action Menu

## 4. Dashboard
โครงสร้าง
- Filter ระดับโครงการ/พื้นที่/ช่วงเวลา
- Summary Cards
- Charts
- Notifications
- Latest Activities
- Quick Actions

## 5. Activity Management
โครงสร้าง
- Activity Information
- Schedule/Rounds
- Registration Form
- Payment Setting
- Evaluation Selection
- Publish Setting

## 6. Registration
โครงสร้าง
- Event Summary
- Participant Information
- Additional Questions
- Payment/Slip Upload
- Consent
- Confirmation

## 7. Evaluation
โครงสร้าง
- Evaluation Header
- Progress
- Question Groups
- Validation
- Submit Confirmation
- Success State

## 8. Report
โครงสร้าง
- Filter
- Summary
- Chart/Table
- Export
- Drill-down
